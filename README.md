# Loan Approval Prediction Using Python

## Project Overview
This project focuses on analyzing loan application data to understand the factors that influence loan approval decisions.

## Objectives
- Analyze loan applicant information.
- Identify loan approval and rejection patterns.
- Understand the impact of applicant income, credit history, and property area.
- Perform Exploratory Data Analysis (EDA).

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Scikit-learn

## Dataset Information
The dataset contains loan applicant details such as:
- Gender
- Marital Status
- Dependents
- Education
- Applicant Income
- Co-applicant Income
- Loan Amount
- Credit History
- Property Area
- Loan Status

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Loan Approval Analysis

## Key Findings
- Total loan applications analyzed: 542
- Approved applications: 376
- Rejected applications: 166

## Conclusion
This project helps understand loan approval patterns through data analysis and visualization using Python.
